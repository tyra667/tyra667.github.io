ABOUT DASHR

DashR is a free browser platformer made by Tyra667, an engineering student who builds games and electronics projects in his spare time. It is written from scratch in vanilla HTML5, CSS and JavaScript: no game engine and no framework. Open the page and play.

THE GAME

DashR is a precision platformer about speed and movement. You run, jump, dash and chain wall-jumps to reach platforms that look out of reach. Dying respawns you instantly at the start of the level: no lives, no checkpoints, just the timer and the goal.

The game has 15 levels in three worlds: the sunlit Meadow (levels 1–5), the dark Iron Caverns (6–10) with teleport portals and tighter layouts, and the Desert (11–15), from the Scorched Plains to the Infernal Desert.

FEATURES

  • Precision dash and wall-jump combos
  • Moving platforms, patrolling enemies and teleport portals
  • Best time per level, plus a total run timer
  • Ghost mode: race your own best run
  • Public online leaderboard (optional, nickname only)
  • Title screen with volume settings, key remapping and a character dressing room (11 colour presets, including an animated Rainbow)
  • Procedurally generated background decorations and chiptune sound effects (Web Audio API)
  • Touch controls: virtual joystick and buttons on mobile

HOW IT IS BUILT

  • HTML5 Canvas for all rendering, written in a single file
  • Web Audio API for procedural sound effects
  • Supabase database for the leaderboard only
  • Hosted on GitHub Pages
